# 自然创作与连续修改

每轮入口、提问与授权见 intake.md；套图回复交完整拍摄脚本，见 storyboard.md §SB-1。

## 画幅与影调记录

单图新建按主体/交付选画幅，编辑沿父版适用要求，不为无关修改重选。套图默认见 storyboard.md §SB-2。目标画幅和实际选用影调分别用 `prepare.changes` 的 `aspect_ratio`、`tone` 记录：自主选用 `ai_design/default`，用户点名按真实来源，已有要求不重复添加。只说横/竖时同一 `user_explicit` 值注明具体比例属设计选择，以便替换父版显式比例；机位另记，改比例仍用 `aspect_ratio`。不从输出倒推意图，成图另核实际像素比例和边缘裁切；影调只在有实际设计作用时记录，不强制选择亮中暗。`画面来源` 缺失补写例外见 intake.md“需求记录”。

## 反馈与再拍

一次接全反馈，区分用户要求、参考、设计与默认；新要求只替代适用目标/分支，明确“整组都”才共享。手、餐具、接触、阴影按目标联动，不拆问；“更暗但菜清楚”可实现，不算冲突。

单图“没感觉/不够好吃”对照当前图和目标给少量有据假设及最小改法，不默认压暗/加暖/旧物；缺图说明依据脚本推测，不编观察。单图方案按 intake.md“方案表达”，信息足够依授权推进。

“再拍一套”先判目的：未评好坏且未说目的，问改善、换拍法还是换几帧并推荐，不抢写新脚本；具体问题只改受影响项，策划错改相关脚本，手等画面错保脚本重拍坏帧。重拍张数≤总数一半，推荐局部并报节省数。只说不好先自查最可能 1–2 个问题并标假设，用户否定后再问哪里，局部不扩全组。新套、复用与连续参照见 storyboard.md §SB-13、§SB-12。

## 换菜与选版

换菜新建 Work、保留旧作品，仅借用户明确偏好并首句说明沿用/重判了什么；明暗偏好按 storyboard.md §SB-3，AI 自选器物/场景/拍法依新菜重判，技术借用见 state.md。

“看第一版”只展示；“回第一版继续”才设编辑目标，叠该版快照、适用共享要求及本轮反馈，不混其他分支局部条件，后续版本保留。`latest`、选中、编辑目标分开，晚到结果不抢目标；数字/字母标签固定 Version，明确选择用 `select_label`，后续可沿目标改。多结果“第二项”先消歧，新多项组恢复歧义，不以最后图或单个子结果兜底。可选有瑕疵图继续，问题记录不改。

按 photography.md P-CHECK 核改善；漂移时说明与较好版差异、推荐回该版另开分支，推荐不等于选中或额外授权。局部保留选可满足工具；仅有整图重画且会超保留范围须说明取得同意，不承诺原生精确像素/区域保护，复杂动作/多参考/局部修补须实证。

## 创意探索与交付

探索按用户数量，未指定通常给 2–3 个实质不同画面（故事时刻、食物状态、场景器物、光色、取景），区别可在占比、距离、环境或动作，不必全变；推荐一项并解释与目标关系，允许混选、删元素及多项修改。明确要图/委托自主时不强制选风格；感觉词见 styling.md。探索、点评、实拍只给建议，不生示范或擅存修图版。

单图/修图交付实际图片、稳定标签和必要限制，用户说够了就保存结束、不加赠。历史偏好、运行与视觉证据仅在原范围有效，模型推荐不替代用户选择。

## 比例预设与多比例裁切

点名比例/常用叫法用本地 `crop`，0 次生成，不问发布用途。

|比例|叫法|400×300 中心最大框|
|---|---|---|
|1:1|方图|[50,0,350,300]|
|3:4|竖图（图文常用）|[87,0,312,300]|
|4:5|略方竖图|[80,0,320,300]|
|16:9|横屏|[0,37,400,262]|
|9:16|竖屏全屏|[116,0,284,300]|

宽 W、高 H、目标 a:b：若 W×b>H×a，新宽=⌊H×a÷b⌋、左=⌊(W−新宽)÷2⌋，框=[左,0,左＋新宽,H]；否则新高=⌊W×b÷a⌋、上=⌊(H−新高)÷2⌋，框=[0,上,W,上＋新高]。主体偏心可平移不改尺寸并说明；取整误差≤1 像素，不承诺精确尺寸。

多比例从同一版本分别 `local_edit` 得独立版本，不串行裁切，按比例名交付；比例差大先说裁掉什么，或建议目标画幅重拍（1 次生成）。
