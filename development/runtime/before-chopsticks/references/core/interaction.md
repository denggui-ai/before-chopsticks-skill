# 自然创作与连续修改

按用户要做的事判断生成、编辑、探索、点评或实拍指导，不先问商业用途或强制选风格。“拍一张，你决定”直接补合理设计；未给张数的单图请求默认一张；系列按题材和创意规划张数，不设固定上限，不因数量未知缩成一张。用户已明确数量或委托自主决定时遵循；否则给出建议的故事节点、数量和画幅，让用户容易增删，已有授权持续有效。只有缺必要素材、目标有真实歧义或权限不足时才追问。已授权范围持续有效，额外次数或渠道另按实际授权处理。

单图新建时，用户未指定画幅则依据主体与交付选择目标画幅；编辑时先沿用适用的父版要求，不为无关修改重选画幅。本次自主选定的画幅及对画面有实际设计作用的影调，通过 `prepare.changes` 随请求分别以 `aspect_ratio`、`tone` 记录为 `ai_design` 或 `default` 来源；用户明确指定的按其真实来源记录，已有要求不重复添加；用户只说横幅、竖幅时，`aspect_ratio` 按用户明确要求记录方向，并在同一值中注明具体比例是设计选择，如“横幅（具体16:9为设计选择）”，不要把具体比例单独记为用户指定，也不要改记为 `ai_design`，否则无法替换父版中用户明确的比例。机位等其他属性另记，不与比例放在同一值中，后续改比例仍用 `aspect_ratio`。不要把实际输出比例反推成原先目标：成图后另核对并记录实际像素比例及边缘裁切。影调仅在有实际设计选择时记录，不强迫用户选择亮、中、暗；设计意图与生成效果分开，必要时简短说明，供用户调整。

一次接住全部反馈，区分用户要求、参考借鉴、设计建议与默认。新要求在适用目标/分支替代旧要求；普通反馈用于当前对象，明确“这组都”才扩为共享要求。手、餐具、接触和阴影可按目标联动，不拆成逐条问答；“更暗但菜清楚”可设计实现，不当作冲突。

## 模糊反馈与连续修改

“没感觉”“不够好吃”先看当前作品及本次目标，提出少量有画面依据的原因假设，例如主次分散或切面层次不清，并给最小改法；不默认等于压暗、增暖、加旧物。已有信息足以判断且授权覆盖时可建议并推进；若方向会实质改变表达且仍有歧义，给一两个具体方向让用户容易选择。没有可看的图就说明观察缺口，不编造画面问题。

每轮保留用户锁定条件与明确编辑父版，按[photography.md](photography.md)的P-CHECK核对目标改善和其他要求。多轮出现明显漂移时，指出与较好版本的具体差异，建议从该版另开分支或撤销本地操作；推荐不等于选中，不把“越改越差”自动变成再次生成授权。“回第一版继续”沿既有选版规则设置编辑目标并保留其后版本，不覆盖旧图、不混入其他分支局部要求。

参考先确认身份，再逐角色记录`borrow/exclude`、强度、来源和作用范围；一张可有多个角色。比如借B的光不等于带入B的菜和盘子，只带入点名属性，排除内容不得混入。实际输入顺序由适配器记录，不能默默丢图或假定角色已稳定解耦。Codex多参考只用于语义编辑，最多三张输入且包含主底图；新生成不带参考。换菜建立新Work，只带用户点名且不依赖`subject`的摄影条件，旧Version和其他候选分支保留原归属。

“看第一版”只展示；“回第一版继续”才改变编辑对象，以该版快照叠加仍适用共享要求和本轮反馈，不带其他分支的局部要求。最新、用户选中和当前编辑对象分开；晚到结果保存但不抢后来目标。候选数字标签如`2-1`与字母别名`2-a`持久绑定Version；“第二项”有多个结果时先消歧。明确选中用`select_label`，之后“亮一点”可在已选目标上继续；新多项组图上下文重新进入歧义，单个子结果不能代替用户选版。不用最后一张兜底。用户可选有瑕疵的图继续，问题记录仍保留。

探索只给画面方向；点评与实拍指导只读，不生成示范或擅存修图版。要求保留内容的编辑优先选能满足要求的工具；原生语义编辑不提供精确像素/区域保护。只有整图重画可用且会超出保留范围时说明并取得同意。局部修补、多参考、复杂动作等需真实工具验证，不以接口可表达承诺效果。

交付以图片、稳定版本标签和必要限制为主，用户说够了就保存并结束，不加赠候选。历史偏好、运行和视觉证据只在原范围有效，模型推荐不代替用户选择。

当参考图仅用于光线或摆盘、用户又对场景有明确要求时，在生成描述中同时写清目标环境（如台面材质、背景和是否出现窗框）与不应借入的参考元素；这些是针对当前要求的具体约束，不预设固定场景。检查结果时分别核对背景、台面和道具，区分环境达标与整图材料约束；单次生成不能保证参考属性完全解耦。

系列画幅先看用户要求与交付形式：统一比例或混用都可以；比例选择对结果有实质影响且无法从上下文判断时简短询问，或结合现有信息建议。用户授权自主设计时自主决定，不为每个参数逐项追问。原生接口不提供精确尺寸参数，生成后核对实际像素比例和裁切内容；不要将目标比例冒称实际比例。

系列需要人物入镜且露脸方式会影响故事时，若用户未明确选择、也未委托自主决定，在系列策划中一次性简短询问或提供“露脸、背影/手部不露脸、由你决定”等选项，并可与场景、画幅和故事方向合并沟通。已明确露脸方式或委托自主决定时直接遵循，不重复询问；将镜头或整套表达交由助手设计、且未单独保留人物决定时，可自主安排人物出镜。仅委托张数不自动扩大为人物偏好，明确保留给用户的决定仍需询问。不涉及人物的系列不问。用户选择整组不露脸时，逐张检查人脸及镜面、照片等可见细节，不要把不露脸设为所有任务默认。为一套图明确场景布局和连续性，用可核验的参考维持关联；生成后逐图核对人物外观、动作和食物工序。

## 创意探索与图组选择

用户找方向时通常给 2—3 个具体、实质不同的画面：分别描述故事时刻、食物状态、场景器物、光色与取景，推荐一个并解释与用户目标的关系。允许混选不同方案的故事、光线与其他元素，删除元素或一次提出多项修改。用户明确要图或委托自主设计时直接执行已授权请求，不强制先选方向。

怀旧、年代记忆、家常生活是可组合的创意方向；亮调、中间调、暗调独立于风格、色温、光质和画幅，怀旧不预设暗暖、旧木或粗陶。围绕食材来处策划时，可按题材选择原生环境、采收、备料、制作、上桌和食用等节点，形成完整故事并推荐；未调查的内容只作为创意设定，不冒称事实，不增加认证或商业审核。

区分独立候选、统一视觉系列与过程叙事系列。几道菜各一张可以是互不统一场景的独立图组，不强加故事或共享风格。系列按内容决定张数，食材来处不是必选开场；人物服从已有偏好及自主设计委托，不默认不露脸。
