# 设计默认值：风格、菜型与菜系、画面场景、统一优先级

先按本节判断任务，再按需查菜型、地域与校验表。这些是候选默认，未经普遍实图验证；不得写成效果承诺。冲突统一按文末优先级。

## 任务边界与路线

- 创作（单图、套图、几个方向）默认只锁菜的身份签名，避免变成另一种菜；修图默认保菜、器皿、人物、搭配食物及有含义物件。用户锁地点时保地点含义；用户明确允许更换的项依其指令更新。
- 修改只执行明说改动及必要联动；用户可明确推翻原保留项。不为默认路线额外加人、加器物；只调色、裁切、局部修改不擅换台面。套图点名某张只改那张，不重写整套脚本。
- 默认路线为人间烟火，目前是 Owner 的设计决定：简短输入常缺场景，这种做法能补一个具体生活情境，已有包子实验依据；非中餐及跨菜适用性【待验证】，不能说适合所有菜。
- 两种退出：白底是交付规格，主体按原样或精修、背景纯白或透明，不加生活痕迹；用户点名米其林、精致摆盘、餐厅出品，或照片本身为餐厅精致摆盘时，直接给餐厅方案：“画面：精致摆盘、干净台面；光线：店内……；道具：……”。光线处落到店内具体光源，如餐厅窗边柔光或店内灯光，不加家常生活痕迹。
- “干净／高级感”仍走默认路线，将画面收干净；电商主图也不自动退出或转白底。白底与生活感同时提出时直接问一句并附推荐：“保留纯白背景，还是改成生活场景？我推荐……，因为……。”推荐按当前主目标选择，用画面结果解释取舍，两种方案不混成一个。
- 人间烟火指真实发生的一刻，有人在做或吃、符合时刻的真实光源（白天通常窗光）、清楚层次、用过但干净的器物、克制配色和故事；创作默认不露脸，不让用户选露脸方式，用户已明确的安排优先。修原片的人物保留按上述修改边界处理，不自动裁掉原有人脸。婴儿辅食的器物用全新极净状态。
- 人间烟火是摄影作品，不是随手拍：生活感来自内容（动作、痕迹、真实光源），作品感来自光与镜头。默认：① 一个主光源从一侧来（窗或灯），暗部自然衰减、不补满，用明暗塑出食物体积；② 主体清楚，背景至少退一层虚化，环境只交代到读得出情境为止，需看整道菜时只让菜清楚；③ 斜俯或平视镜头用较近距离和偏长焦的压缩感，避免站着用广角俯拍整桌的手机视角，顶拍不受此限；④ 每张一个主体，陪衬物件两三样以内，人物只露完成动作所需部分。逐图 prompt 用正面描述写这些拍法，不写“非广告／非摆拍”之类反向措辞。用户明确要手机感或随手拍时从其要求。


## 四个维度，互不重叠

| 维度 | 是什么 | 决定什么 | 从哪来 |
|---|---|---|---|
| 菜型 | 怎么做出来的（制法、形态） | 最该抓的那一刻、色彩要点、常见器皿与吃法 | 看图识别 |
| 地域菜系 | 哪里的饮食传统 | 器物、做法与吃法的地域差异 | 看图识别；认不准就不用 |
| 画面场景 | 什么吃饭时刻 | 份数、餐具套数、配搭、道具 | 看图推断＋用户话语 |
| 约束标签 | 饮食限制（素食/斋、清真） | 画面里不能新加什么 | 用户说明或明确识别；拿不准不贴 |

- 识别出菜后先定主菜型（可有次菜型），再看地域菜系、画面场景、约束标签；认不准的一律不用。
- "日式""中式"：菜本身是什么从食物识别；用户说"做成日式"指风格。例："把红烧肉做成日式"＝红烧肉（菜型红烧）＋日式风格。
- 器物跟菜的地域与实际吃法，地域也参与做法与动作；融合菜不按菜名补整套地方场景，家常改良不硬归类。认不准的地方物件不硬画，选认得准且适合吃法的器物；此具体方法【待验证】。不把按外形描述物件当已验证修法。

## 菜型（14 类）

一道菜属于多个菜型时，按被拍摄的那一刻定主菜型，次菜型只补色彩。例：小笼汤包——主面点（褶子、皮薄），次汤羹（汤汁）；水煮鱼——主红烧炖煮；煲仔饭——主饭（锅巴）；锅包肉——主烤炸（酥脆挂汁）。

| 菜型 | 最佳状态（该抓的那一刻） | 色彩要点 | 常见器皿与吃法 |
|---|---|---|---|
| 汤面/汤粉 | 汤面油花、面条挑起、浇头完整 | 汤色透，不浑不发灰 | 大碗；筷子挑面、勺喝汤 |
| 汤羹/炖汤 | 清汤透或浓汤有光、热气、勺舀起 | 保持汤的本色 | 汤碗、砂锅；勺 |
| 粥 | 粥面米油、稠度、勺舀起 | 米白不灰 | 碗、砂锅；勺 |
| 饭（炒饭、盖饭、拌饭、煲仔饭） | 炒饭粒粒有油光；盖饭浇头完整、汁挂饭面；拌饭拌开前配料分区；煲仔饭锅巴 | 饭白不灰；锅巴焦黄不焦黑 | 盘、碗、石锅、砂锅；勺或筷子 |
| 炒 | 锅气、油亮、配色分明 | 主料与配菜对比清楚 | 盘；筷子 |
| 蒸 | 刚出锅热气、表皮完整湿润 | 保持食材本色，不过黄（蒸蛋、梅菜扣肉本身就黄或酱色）；白色食材（鱼、豆腐、水晶包）防蒸汽灰蒙、防高光过曝 | 蒸笼、盘；筷子 |
| 红烧/炖煮/卤 | 酱汁挂面、琥珀光泽、一夹就开 | 酱色透亮不发黑 | 深盘、砂锅；筷子 |
| 烤/炸 | 焦边、酥脆纹理、刚出炉或出锅 | 金黄不焦黑，有油光不油腻 | 盘、烤盘、签子；筷子或手 |
| 火锅/涮烫 | 优先拍夹起的一筷子；整锅时锅面浮油克制，翻滚以少量气泡和热气表现 | 汤底按锅底本色，不一律红 | 锅（不写死）、小碟；筷子、漏勺 |
| 凉拌 | 清爽、酱汁刚淋、食材新鲜 | 鲜亮 | 盘；筷子 |
| 生食/生腌 | 切面纹理与光泽、冰鲜感 | 忠于鱼肉本色，白平衡中性（三文鱼本身偏橙）；饱和度别拉满，红肉不发荧光；冰与水珠不过亮 | 冷盘、冰；筷子 |
| 面点（包子饺子馄饨馒头等） | 按品种取适用特征：有褶的褶子清楚、有馅的掰开冒汽露馅、馒头取松软断面；不新增原本没有的馅或褶 | 面皮白而不灰 | 蒸笼、蒸纸、盘；筷子夹、手掰 |
| 甜品烘焙 | 切面层次、酥皮、奶油挺立、刚出炉 | 通透柔和 | 蛋糕盘、烘焙纸、冷却架；叉子、手拿 |
| 饮品 | 冷凝水珠、气泡、拉花、茶汤透亮 | 液体透亮 | 玻璃杯、陶杯；端起、倒、搅（倒液为已知弱项） |

## 地域菜系（中式 9＋外国 4）

认不准就不用，只按菜型；闽、徽及未列的菜系同此处理。台湾小吃、印度/南亚、中东暂不单列，按菜型兜底；便当盒饭不是菜系，按画面场景"盒装"处理。

| 菜系 | 器皿与吃法的地域默认 | 故事线/溯源素材 | 防刻板 |
|---|---|---|---|
| 川渝 | 深盘或大盆、汤碗，视菜而定（水煮、毛血旺多用大盆）；火锅器皿不写死；筷子、蘸碟 | 炒底料、辣椒花椒 | 不默认全红；白油、椒麻、鱼香等非红油菜按菜型走 |
| 粤（含早茶、烧腊、老火汤） | 竹蒸笼、白瓷小碟、茶具；筷子、斟茶 | 清晨茶楼、斩烧腊、煲汤 | 不堆金龙、霓虹港风 |
| 江浙沪 | 青花或白瓷、小碟；筷子、小勺 | 时令食材、水乡市场 | 不默认小桥流水背景 |
| 湘 | 铁锅、土钵；筷子 | 腊味熏制、剁椒 | 不只靠红色，突出锅气 |
| 鲁/北方 | 大盘、汤碗；筷子、公勺 | 葱烧、清汤 | 不默认宴会厅 |
| 东北 | 大盘大碗、铁锅炖；筷子 | 冬天、炖锅热气 | 不靠大花布堆符号 |
| 西北面食（陕甘晋） | 大海碗、粗瓷；筷子挑面 | 和面、拉面、油泼辣子 | 不默认黄土窑洞 |
| 新疆 | 大盘；勺或筷子为主，手抓肉可用手 | 烤馕、大盘鸡、抓饭 | 不加民族服饰；识别为清真菜时挂"清真"约束 |
| 云贵 | 粗瓷碗、砂锅、铁锅，视菜而定；汽锅鸡用汽锅；筷子、勺 | 酸汤、米线、菌子 | 不加民族服饰、图腾；不默认山野竹楼篝火；芭蕉叶仅在识别为傣味时用 |
| 日本 | 小器多样型（定食、怀石、刺身拼）按季选器、留空；单品大碗型（拉面、咖喱饭、丼、炸物）大碗、木盘；筷子 | 鱼市、刀工、熬汤 | 不堆樱花、浮世绘、和风文字 |
| 韩国 | 石锅、不锈钢碗；勺加筷子；烤肉用生菜包肉 | 烤肉、拌饭、腌菜 | 不默认多碟小菜铺满桌；一人一份只摆相关小菜 |
| 西餐（法、意、美式） | 大白盘居中留白、木砧板；刀叉，意面卷起 | 农场、市集、炉火 | 不默认烛台银器 |
| 东南亚 | 泰——勺叉；越——筷子、米粉大碗；马来、印尼——勺叉为主，蕉叶饭仅在识别出时用 | 香草、椰子、街市 | 不默认热带背景 |

故事线与溯源素材属于"我设计的画面"；涉及时令、产地的节点只作画面提示，不写成用户可见的事实陈述。

## 约束标签

| 标签 | 影响 |
|---|---|
| 素食/斋 | 我们新加的东西不出现肉类意象（含背景食材、道具） |
| 清真 | 我们新加的东西不出现猪肉与酒 |

只在用户说明或识别明确时挂；拿不准不贴，也不在回复里猜用户的饮食信仰。只限制我们新加的东西：用户照片里已有的冲突物件不擅删，在首答里点出由用户决定。

## 风格与感觉词

不设固定风格清单。用户点名的词按真实来源记录，展开的光、色、材质、道具与构图记 `ai_design`；用一句可见描述解释本轮怎么做，用户可改。风格名和感觉词不原样进入提示词，改成具体画面条件。复古、怀旧同样解释为本轮选择的色彩关系、材质与物件，不列入明暗表，也不写一组反向禁令。套图只共享适用的条件，不将风格解释整行锁成同一场景。

## 影调默认与证据

先服从用户明确明暗，再判断当前组合。唯一已有生图依据的组合是“包子过程叙事 × 团聚”，可候选低调，以光集中在制作与分享动作、环境退后承载团聚情境；证据仅限这一组，不扩大成面点或中餐通则。其余默认中间调，是未普遍验证的做法。画面设计说明本轮明暗及其依据。

感觉词的以下翻译均【待验证】，仅作本轮可调整的默认：温暖→暖中间调、柔光；有氛围→偏暗、光落在菜上；清爽／早餐→偏亮通透；干净／高级→中间调、背景简、色彩收敛。用户只说有故事时不自动套用“有氛围”的偏暗解释。品味库只有菜类与场景对应的明暗证据，新增行须附生图证据并获 Owner 认可；目前不扩表。影调层次与成图检查见[photography.md](photography.md) P-TONE。

## 画面场景与道具

画面场景是"画面里是哪种吃饭时刻"，不是发布用途：按画面特征命名（店内出品、盒装），不用平台词，不问用途。从照片识别阶段与食物状态，不把原桌面、摆位或拍法当成默认场景模板；按本张故事作用、空间关系、动作与拍法设计场景后再搭配道具，首答说一句，用户可改。场景依据与无依据时的做法统一见[intake.md](intake.md)“创作：策划与方案”，不从校验表选默认场景。

道具按阶段分：

| 阶段 | 道具 | 原则 |
|---|---|---|
| 制作中 | 原料、工具（擀面杖、刀、蒸笼）、半成品、过程痕迹 | 说明正在做什么；与工序先后一致；痕迹按时刻保留 |
| 成品 | 餐具、配菜与饮品、调料碟、餐巾、少量装饰 | 服务"怎么吃、和谁吃" |
| 环境 | 台面、背景、窗光线索 | 交代场景，不抢主角 |

以下仅供策划后的合理性校验，不是选场景菜单，也不强制套用人数或机位。

| 场景 | 人数与餐具套数 | 手 | 取景 |
|---|---|---|---|
| 一人食 | 1 人、一套 | 可无，可一只 | 近景 |
| 两人食 | 2 人、两套相对 | 可无 | 中景 |
| 家宴/团聚 | 多人、多套＋公勺，主菜居中 | 不画多只手，用多套餐具＋有人动过的痕迹表现 | 俯拍或大全景 |
| 店内出品 | 店内份量 | 可无 | 见规则 7 |
| 早餐 | 1–2 人、简单器皿 | 可无 | 清晨光线 |
| 下午茶 | 杯碟成套 | 可无 | 柔和侧光 |
| 夜宵街头 | 签子、纸盒 | 可无 | 夜晚暖光 |
| 野餐户外 | 餐盒、餐垫 | 可无 | 户外自然光 |
| 盒装 | 盒装一份 | 可无 | 俯拍为主 |
| 节令（年夜饭、粽子、月饼、汤圆等） | 依节令 | 可无 | 不堆节日符号 |
| 家常日常（默认） | 按画面时刻推断搭配，不擅改已锁定人数 | 按动作需要，不强加 | 按时刻设计机位、取景与台面 |

配搭（饮品、小菜、调料）按画面推断，不逐场景规定；未列场景按画面具体推断。

1. 保留边界按“任务边界与路线”；创作更换器皿或有含义物件时说明设计，用户已锁定项优先。新加道具点名附理由，用户可否决。
2. 份数、餐具套数、杯子与场景人数一致。不强制画手；要画手时数量不超过场景人数。
3. 道具数量由动作、人数和主次关系决定，不设固定上限，避免无用堆放。
4. 道具种类不违背菜系吃法（小笼包不配刀叉）；我们新加的东西不违反约束标签（清真无酒）。模式内保留的已有冲突物件只点出、不擅删；创作模式已说明替换的物件按方案重设计。
5. 我们新加的东西：不带品牌标签的瓶罐与包装；不出现手机、宠物、杂物；桌布餐巾不抢主角，不做僵硬的整齐褶皱。
6. 使用痕迹随动作和时刻安排，不设一处上限，不为装饰硬加。
7. 店内出品：餐具、招牌等有含义物件按模式保留范围处理；店内背景不默认照抄，用户明确锁定地点时保含义。新加环境只给中性虚化背景，不编造实际店内陈设，不新增真实店名、招牌、logo。
8. 套图的连续条件和转场按[intake.md](intake.md)“创作：策划与方案”逐项落实为文字设计，成图参考只用于两处：同场景且机位高度与第一张相同的镜头从第一张出发（该文件执行顺序第 3 条），以及“同套连续性参考”的单张重拍；不串成成图到成图的长链。实际一致性逐张核对，不承诺完全一致。
9. 修改与创作分别按其边界设计，不因单图请求省掉明确角色与动作，也不在修改中擅自增加故事元素。

## 统一优先级

用户明说 ＞ 照片事实 ＞ 用途 ＞ 默认 ＞ 装饰；冲突只换冲突项。照片事实约束菜的身份和真实情境，用途决定呈现方式；不为取得用途再提问。

引擎同键来源顺序仍为 `user_explicit` ＞ `user_reference` ＞ `user_implied_edit_preservation` ＞ `ai_design` ＞ `default`；设计时按上述语义优先级解决不同键冲突。默认身份保留用 `user_implied_edit_preservation`，参考借法记 Reference roles，展开设计用 `ai_design`，不以 `user_reference` 覆盖用户照片身份。
