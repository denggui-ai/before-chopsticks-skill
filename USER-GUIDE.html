动筷之前

本地 Codex 美食摄影创作助手 · v13 开发候选（未发布）· 2026-10-31

能做什么

给一道菜、照片或想法，探索画面、生成图片、连续修改、选版或策划系列。也可点评照片、指导实拍和进行基础调色裁切。照片是可选输入；请勿提供不愿发送给图像服务的敏感素材。

兼容与依赖

需要本地 Codex、Python 3、Pillow 和支持 fcntl 的系统；生成需要当前可用的 Codex 原生图像工具。macOS 有限定验证；Linux 未验证，原生 Windows 不承诺兼容。开发校验工具另需 PyYAML。具体最低版本、安装耗时和磁盘需求尚未测定。

项目级安装

先检查项目中 .agents/skills/before-chopsticks 是否已存在；如存在，先将其完整复制备份。将公开源码中的 development/runtime/before-chopsticks 完整复制到该位置（包括 LICENSE），在项目内开启新 Codex 会话。检查会话能否发现该 Skill；发现与实际完成任务是两项不同验证。

入口一：明确要图，直接创作

说“来一张红烧肉，竖幅，其他你决定”，会简短说明设计后直接生成一张，不先让你选风格或方向；附上自己拍的照片说“保留这盘菜，换成干净的浅色台面”，会以该照片为底图做生成式编辑，不保证像素不变。之后可以说“背景再简单点，颜色别那么黄”继续修改，“就用 2-b”选定候选，“看第一版”只查看，“回第一版继续”从第一版另起一支且保留其他版本，“导出 PNG”另存导出文件，“够了”结束。已说清的要求和授权不会被反复确认。

入口二：先找方向，再决定生成

说“红烧肉先给几个不同方向，不生图”，会得到通常两到三个具体画面及推荐，不调用图像工具；说明数量时按数量给。可以继续说“怀旧，但要亮调”或“第二个故事、第一种光，不要手”来混选，满意后说“就按这个出图”才开始生成，之后同入口一。多道菜各一张不必统一场景。详细话术见 Markdown 使用说明，能力与验证范围见 v13 能力清单。

权限、隐私和限制

文字策划、点评、实拍指导不自动生图。本地调色与裁切在本地执行；生成和生成式编辑需要可用工具和用户授权，可能消耗账户用量并将提示词、输入图片发送服务端。素材、版本和调用记录保存于所选作品目录；服务端保留规则由服务提供方决定。失败或提交状态未知不会自动重发。没有可满足精确保留要求的工具时说明限制，不能承诺像素不变。

整图改光一致性、倒液保留、多参考属性解耦、复杂动作及跨题材稳定性有限；作品需逐图复核。完整新会话自动出图链未验证。

升级前备份旧安装，再替换运行目录。回退时移除新安装并恢复备份；独立备份恢复尚未实际演练。卸载仅移除项目级 Skill 目录，作品目录不会自动删除；迁移旧作品数据尚未验证。
